## What I'm working on

At T-Bank I own the frontend of two Angular 19 applications in an Nx monorepo — a self-service portal used by around 4,000 employees a month, and an admin console for internal moderators. That means NgRx state, Taiga UI, typed API clients generated from four backend Swagger specs, OAuth2/OIDC, bilingual localisation, unit tests in Jest and end-to-end tests in Playwright. There is no dedicated designer on the product, so I design the screens too.

I also work outside the frontend where it helps: backend endpoints in NestJS, React micro-frontends for adjacent products on the platform, and Grafana dashboards on Prometheus metrics to see how features are actually used.

Before this I owned SSR, prerendering and NGXS state architecture on a high-load gaming and marketplace platform, and spent two and a half years on rotating outsourcing projects across CRM, e-commerce and corporate web.
